Inkast / 原型 v6 · 比例/尺寸两层 + 覆盖规则

这版变更点

  • 跳过文本按钮加 → 箭头(指向右侧字段编辑器)
  • 比例 chip 扩展:1:1 / 2:3 / 3:2 / 9:16 / 16:9 / 3:4 / 4:3 / 4:5 + 自定义(展开两个数字输入)
  • 尺寸 = 两层:基于比例的常见尺寸候选 chip(`512²` / `1024²` / `2048²` ...)+ 自由输入 W × H
  • 覆盖规则:用户手填了尺寸数字 → 比例 chip 全部 disable 灰掉,旁边出现「清空」
  • 清空:清空尺寸 → 比例 chip 恢复可点,回到「按比例走」(用比例预设的默认尺寸)

覆盖规则

  • 用户在尺寸 input 里敲了 1500 × 900
  • 比例区整块 灰掉 + 不可点(opacity 0.42 + pointer-events: none)
  • 底下出现 ⊘ 已被下方手填尺寸覆盖 · 点「清空」恢复 提示
  • 尺寸 input 右侧出现 🗑 清空 按钮(accent 色)
  • 点清空 → 尺寸两个 input 清空,比例区恢复可点,回到「按比例走」
