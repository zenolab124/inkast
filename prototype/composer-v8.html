Inkast / 原型 v8 · 取向 → 比例 → 尺寸 三层级联

这版的模型

  • 三层独立维度,逐级筛选:取向(粗) → 比例(细) → 尺寸(具体像素)
  • 取向 方/横/竖/自定义 = 筛选器,只影响下面「比例 chip 列表」
  • 取向 = 自动 / 方 / 横 / 竖 / 自定义,共 5 个 chip。「自动」=取向/比例/尺寸全交给 provider 决定,我们不传这些参数
  • 比例 chip 仍然全在(只是按取向过滤),用户在这里挑具体的宽高比
  • 尺寸候选是当前比例下的几个常见值,带 ★ 的是广泛兼容档
  • 取向「自定义」→ 比例区直接展开 W : H 输入框,没有比例 chip
  • 手填了尺寸 → 取向 + 比例 整块灰掉,旁边出现「清空」
  • 注意:设定的尺寸不一定跟出图的尺寸保持一致(取决于你的 provider)

切到横之后

取向 [横] → 比例 [3:2 / 16:9 / 4:3 / 21:9] → 尺寸 [3:2 下的常见值]
