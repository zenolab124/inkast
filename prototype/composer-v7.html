Inkast / 原型 v7 · 方/横/竖 + 尺寸标签

这版变更点

  • 「比例」收敛到 方 / 横 / 竖 / 自定义 4 个 chip
  • 细比例(3:2 / 16:9 / 4:3 等)下沉到尺寸候选标签:每个尺寸 chip 显示 3:2 1536×1024 这种「比例 + 实际尺寸」
  • 带 ★ 的尺寸 = gpt-image-2 原生支持的标准档,不带 ★ 的 = 数学合法但上游可能拒
  • 「按方向走」时默认选中带 ★ 的标准档
